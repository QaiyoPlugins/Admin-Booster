# Security Policy

## Supported versions

The latest released version of Qaiyo Admin Booster receives security updates.
Please always run the most recent version available on WordPress.org.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅         |

## Reporting a vulnerability

If you discover a security vulnerability in Qaiyo Admin Booster, please report it
privately so we can fix it before it is disclosed publicly. **Do not open a public
issue or forum topic for security problems.**

- **Email:** info@qaiyo-plugins.com
- Please include: the plugin version, a description of the issue, the steps to
  reproduce it, and (if possible) a proof of concept.

### What to expect

- We aim to acknowledge your report within **72 hours**.
- We will keep you updated on our progress while we investigate and prepare a fix.
- Once a fix is released, we are happy to credit you in the changelog (let us know
  if you prefer to stay anonymous).

We appreciate responsible disclosure and thank you for helping keep Qaiyo users safe.
